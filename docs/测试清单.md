# 现场测试清单

## 首次安装

1. 打开 App，确认首页显示“快速读取与检尺计算”“导入新的 XLSX 舱容表”“船舶资料库”。
2. 点击“导入内置示例表”。
3. 核对识别到的船号、船舱数量、点数和空高范围。
4. 对“未识别或按顺序映射”的船舱，在船舶详情页修改映射。

## 快速计算

1. 输入完整船号，例如“新平江1014”。
2. 检查完全匹配结果。
3. 选择船舱，输入毫米空高。
4. 切换为米单位，再用等价值复算。
5. 检查 H1、H2、V1、V2、比例、未舍入值和最终三位小数。
6. 输入小于最小值和大于最大值的数据，确认禁止外推。

## 文件与版本

1. 在 App 内浏览每个 Sheet。
2. 使用 WPS/Excel 打开原始文件。
3. 重复导入同一文件，确认不重复写入。
4. 导入同船新版表，确认新版本成为当前版本。
5. 删除船舶，确认资料库和孤立原文件同步清理。

## 上线前

- 使用现场所有常见船型样表做回归测试；
- 每艘新船首次导入后人工核对船号、船舱映射、空高范围和若干抽样容积；
- 与现行 Excel 公式至少抽查低、中、高三个空高区间；
- 在正式业务设备上验证离线导入、计算和原表打开。


## 原油综合计算

- [ ] 船舱数超过 12 时明确阻止，不静默截断。
- [ ] 空舱取消勾选后不要求空高和温度。
- [ ] 空舱不参与平均油温。
- [ ] 各舱空高超范围时阻止整船计算。
- [ ] `850 kg/m³` 与 `0.850 t/m³` 得到相同质量。
- [ ] 水体积按 m³ 直接从总检尺容积扣除。
- [ ] 页面输出顺序符合需求。
- [ ] XLSX 顶部入口能使用 WPS/Excel 打开。
- [ ] XLSX A1:L26 版式保持，A26:L26 拆成四个区域。
- [ ] 页面、XLSX 缓存值、XLSX 公式复算结果一致。


## 1.1.1 输出兼容测试

- [ ] 管线量留空时按 `0 m³` 计算。
- [ ] 水体积留空时按 `0 m³` 计算。
- [ ] OBQ 留空时按 `0 m³` 计算。
- [ ] 商检量留空时按 `0 t` 计算。
- [ ] 计算完成后立即显示结果页，不自动依赖 XLSX。
- [ ] PDF 报表可生成、打开或分享。
- [ ] Excel/XLSX 报表可在出现过 XML 兼容错误的设备上生成。
- [ ] 纯文本结果可查看、复制和分享。
- [ ] 单个导出失败时，另外两种输出仍可使用。
- [ ] PDF、Excel 和页面显示的数据保持一致。
