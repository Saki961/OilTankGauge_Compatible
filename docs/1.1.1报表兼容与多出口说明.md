# 1.1.1 报表兼容与多出口说明

## XLSX 设备兼容修复

部分 Android 系统内置 XML 解析器不支持 Xerces 特性：

```text
http://apache.org/xml/features/disallow-doctype-decl
```

旧实现直接执行 `DocumentBuilderFactory.setFeature`，设备不支持时会在读取内置 XLSX 模板前抛出异常。

1.1.1 改为逐项尝试 XML 安全特性：

- 系统支持时继续设置；
- 系统不支持时跳过该项；
- 报表仍只读取 App 内置可信模板；
- 不再因设备 XML 解析器差异阻断 XLSX 输出。

## 可选输入

以下字段留空时自动按 `0` 计算：

- 管线量；
- 水体积；
- OBQ；
- 商检量。

密度、VCF、参与船舱的检尺空高和中部温度仍为必填。

## 三种独立输出

计算完成后先进入结果页，随后可分别选择：

1. PDF 报表；
2. Excel/XLSX 报表；
3. 纯文本结果（查看、复制、系统分享）。

任何一种导出失败，都不会影响页面计算结果和另外两种输出方式。
