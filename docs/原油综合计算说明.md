# 原油综合计算说明

## 功能入口

首页选择“原油综合计算与 XLSX 输出”。

## 输入

- 最多 12 个船舱。
- 每个非空船舱输入检尺空高（mm）和中部温度（℃）。
- 空舱取消勾选，不参与检尺容积汇总，也不参与平均油温。
- 整船输入：管线量、水体积、OBQ、VCF、商检量、密度。
- 密度可选择 `kg/m³` 或 `t/m³`。

## 计算公式

```text
总检尺容积 = 各非空船舱检尺容积之和 + 管线量
平均油温 = 各非空船舱中部温度平均值
钢膨系数 = 1 + (平均油温 - 20) × (0.000012 × 3)
无钢膨总标准体积 = (总检尺容积 - 水体积) × VCF - OBQ
有钢膨总标准体积 = 无钢膨总标准体积 × 钢膨系数
```

密度统一换算成 `t/m³` 后：

```text
修正密度 = P20 - 0.0011
无钢净表观质量 = 无钢膨总标准体积 × 修正密度
有钢净表观质量 = 有钢膨总标准体积 × 修正密度
无钢膨量差 = 无钢净表观质量 - 商检量
有钢膨量差 = 有钢净表观质量 - 商检量
```

当用户选择 `kg/m³` 时，程序先除以 1000，再执行 `P20 - 0.0011`；等价于直接执行 `kg/m³` 口径的 `P20 - 1.1`。

## XLSX 输出

- 模板：`app/src/main/assets/report/原油计算模板.xlsx`
- 保留“原油计算”工作表 `A1:L26` 的原始版式、合并单元格、边框、字体、列宽和打印区域。
- 第 26 行改为：
  - `A26:C26`：无钢膨量差标签
  - `D26:F26`：无钢膨量差数值
  - `G26:I26`：有钢膨量差标签
  - `J26:L26`：有钢膨量差数值
- 报表结果单元格保留可复算公式，同时写入 App 计算得到的缓存值。
- 报表文件保存在 App 私有目录 `files/reports`，通过只读 Provider 交给 WPS/Excel 打开。
