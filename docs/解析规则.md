# XLSX 解析规则

1. 直接读取 XLSX Zip/XML，不要求手机安装 Excel，也不引入 Apache POI。
2. 遍历全部 Sheet。
3. 只有同时出现“容量表/Tank Capacity Table”和“空高/Ullage”的 Sheet 才进入解析。
4. 优先搜索纵倾表头 `0.0m`：
   - 找到后，搜索其左侧的空高列；
   - 只读取空高与 0.0m 容积列。
5. 没有纵倾矩阵时，识别重复的“空高 + 容量”列组。
6. 支持同一 Sheet 横向放置两组数据。
7. 支持部分行把空高、容量、厘米差挤在同一单元格。
8. 清洗星号、换行和说明文字，提取数值，同时保存原始文本。
9. 空高统一转换成整数毫米。
10. 明显大于 10000 的容积数按缺失三位小数处理，例如 `285867 → 285.867`。
11. 根据船号与统一船舱名合并跨 Sheet 数据。
12. 相同空高出现冲突时，保留可信度较高值并产生警告。
