# v1.2.0 原油检尺交互升级

本版基于 v1.1.1 工程直接升级，重点对应现场提出的 4 项需求。

1. 综合计算每舱温度允许留空，留空按 0℃ 参与现有平均温度/钢膨公式。
2. 每舱增加“下尺 / 浸油自动计算空高（可选）”。两项同时填写时按 `空高 = 下尺 - 浸油` 自动回填；两项都不填时仍可人工输入空高。
3. 综合计算结果页增加“返回修改（保留本次填写）”和“新建计算（清空填写）”。返回修改会恢复船舶、各舱勾选、空高、下尺、浸油、温度以及整船参数。
4. 船舶详情增加“舱容数据自查”。只检查当前活动数据集中 App 实际用于取数/插值的 capacity_points，不遍历未采用列；按本舱常见空高间隔、相邻容积变化、趋势和识别可信度提示异常，并显示来源 Sheet/单元格。
5. 首页增加“总量快速复核”。无需逐舱录入，输入总检尺体积、底水、OBQ、VCF、标密即可按综合计算的无钢膨口径计算质量；可选填写商检结果查看差值和差率。
6. 首页按“原油计算 / 船舶舱容资料”分组，减少入口堆叠。

## 本版计算口径说明

- 下尺/浸油自动空高：`空高(mm) = 下尺(mm) - 浸油(mm)`。
- 快速复核标准体积：`[(总检尺体积 - 底水) × VCF] - OBQ`。
- 快速复核密度修正与原综合计算一致：P20 转成 t/m³ 后减 0.0011 t/m³。
- 快速复核主结果采用“无钢膨”质量，目的是快速核对外部/商检计算；正式报表仍使用综合检尺计算。

## 建议重点测试

- 12 舱全部温度留空是否能正常计算。
- 任意舱仅人工空高；以及下尺+浸油自动回填空高两种方式。
- 结果页返回修改后全部字段是否恢复，修改一个舱后能否重新计算。
- 船舶详情 -> 舱容数据自查，正常表是否误报过多，人工构造异常点时是否能提示来源单元格。
- 总量快速复核与综合计算中相同“无钢膨”输入的质量结果是否一致。
