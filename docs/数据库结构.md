# 数据库结构

## vessels

每艘船一条主记录，以标准化船号唯一匹配。

## source_files

保存原始 XLSX 的文件名、本地路径、SHA-256 和导入时间。相同文件哈希不会重复导入。

## datasets

同一艘船可以有多个舱容表版本。新版本导入后成为活动版本，旧版本保留在数据库中。

## tanks

属于某个数据版本的船舱，保存统一名称和原表名称。

## capacity_points

每个空高—容积数据点，保存：

- 空高整数毫米
- 容积十进制文本
- 固定纵倾 0.0m
- 来源 Sheet
- 来源单元格
- 原始单元格文本
- 识别可信度

## calculation_history

保存船舶、船舱、输入空高、结果和计算时间。
